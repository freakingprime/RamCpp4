# Formatting Templates
# Available tokens:
#   {cpu}              - CPU usage % (0-99, 2-digit fixed width via space padding)
#   {ram_percent}      - Used RAM % (2-digit fixed width via space padding)
#   {ram_free_percent} - Free RAM % (2-digit fixed width via space padding)
#   {ram_used_gb}      - Used RAM in GB (4-char fixed width, e.g. 7.8)
#   {ram_free_gb}      - Free RAM in GB (4-char fixed width)
#   {ram_total_gb}     - Total RAM in GB (e.g. 16.0)
#   {net_down}         - Download speed in Mbps with 1 decimal (e.g. 4.8, 150.2)
#   {net_up}           - Upload speed in Mbps with 1 decimal (e.g. 1.2, 42.5)
#   {net_down_mb}      - Download speed in MB/s with 1 decimal (e.g. 15.6)
#   {net_up_mb}        - Upload speed in MB/s with 1 decimal (e.g. 2.1)
#   {net_down_int}     - Download speed in Mbps whole integer without decimal (e.g. 5, 150)
#   {net_up_int}       - Upload speed in Mbps whole integer without decimal (e.g. 1, 42)
#   {net_down_mb_int}  - Download speed in MB/s whole integer without decimal (e.g. 16)
#   {net_up_mb_int}    - Upload speed in MB/s whole integer without decimal (e.g. 2)
# (Aliases: {net_down_0}, {net_up_0}, {net_down_mb_0}, {net_up_mb_0})
